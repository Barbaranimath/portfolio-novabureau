# Quiz : hameçonnage et MFA (5 questions)

Durée : 5 minutes. Les réponses et explications sont à la fin.

---

**1. Vous recevez ce courriel fictif : « Votre boîte courriel est pleine. Cliquez ici d'ici 1 heure pour éviter la suppression de vos messages. » Quel est le signal d'alarme le plus important ?**

- A) Le message parle de votre boîte courriel
- B) Le délai très court qui vous pousse à agir sans réfléchir
- C) Le message est en français
- D) Le message ne contient pas de pièce jointe

**2. Vous survolez un lien affiché « portail.novabureau.example ». L'adresse réelle est `portail-novabureau.example-login.com`. Que faites-vous ?**

- A) Vous cliquez, car le nom NovaBureau apparaît dans l'adresse
- B) Vous transférez le message à vos collègues pour leur demander leur avis
- C) Vous ne cliquez pas et vous signalez le message au soutien TI
- D) Vous supprimez le message et n'en parlez à personne

**3. Votre téléphone affiche une demande d'approbation MFA alors que vous n'essayez pas de vous connecter. Que signifie-t-elle probablement ?**

- A) Une simple erreur technique sans importance
- B) Quelqu'un connaît votre mot de passe et tente de se connecter
- C) Votre compte est en train d'être mis à jour
- D) Le soutien TI teste votre compte

**4. Quelle est la bonne réaction à la situation de la question 3 ?**

- A) Approuver pour que les demandes cessent
- B) Ignorer la notification
- C) Refuser, puis appeler immédiatement le soutien TI pour changer votre mot de passe
- D) Désinstaller l'application d'authentification

**5. Une personne appelle en se présentant comme « le soutien TI » et vous demande votre code MFA pour « régler un problème urgent ». Que faites-vous ?**

- A) Vous donnez le code, car c'est le soutien TI
- B) Vous donnez seulement votre mot de passe, pas le code
- C) Vous refusez, raccrochez et rappelez le soutien TI au poste 2020
- D) Vous demandez à la personne de rappeler plus tard

---

## Réponses

| # | Réponse | Explication |
|---|---|---|
| 1 | **B** | L'urgence artificielle est la technique la plus utilisée : elle empêche de prendre le temps de vérifier. |
| 2 | **C** | Le vrai domaine est ce qui précède le dernier « .com » : ici `example-login.com`. Le mot « novabureau » n'est qu'un leurre. Transférer le message (B) risque qu'un collègue clique. |
| 3 | **B** | Une demande MFA inattendue signifie que la première barrière (le mot de passe) est déjà franchie. Le MFA vient de vous protéger. |
| 4 | **C** | Approuver (A) donnerait l'accès à l'attaquant. Ignorer (B) laisse le mot de passe compromis en circulation. |
| 5 | **C** | Le soutien TI ne demande **jamais** un mot de passe ou un code MFA. En cas de doute, raccrochez et rappelez un numéro connu. |

**Barème** : 5/5 réflexes acquis · 3–4/5 relire le guide [Reconnaître une tentative d'hameçonnage](../07-base-connaissances/06-reconnaitre-hameconnage.md) · 0–2/5 courte rencontre avec le soutien TI.
