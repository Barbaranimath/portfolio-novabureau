# Réinitialiser son mot de passe

**Objectif** : retrouver l'accès à votre compte NovaBureau en moins de 5 minutes, sans attendre le soutien TI. · **Temps** : 5 min · **Prérequis** : MFA activé

## Étapes

1. Allez sur la page de connexion Microsoft 365 et entrez votre adresse `prenom.nom@novabureau.example`.
2. Cliquez sur **Mot de passe oublié ?**
3. Recopiez les caractères affichés, puis cliquez sur **Suivant**.
4. Validez votre identité avec l'application d'authentification sur votre téléphone.
5. Choisissez une nouvelle **phrase de passe** d'au moins 14 caractères (exemple de forme : quatre mots sans lien, avec un chiffre). N'utilisez pas l'exemple tel quel.
6. Connectez-vous avec la nouvelle phrase de passe.
7. **Important** : mettez à jour le mot de passe dans l'application courriel de votre téléphone et sur votre tablette, s'il y a lieu.

## Erreurs fréquentes

| Problème | Solution |
|---|---|
| Mon compte se verrouille encore après le changement | Un appareil (souvent le téléphone) utilise l'ancien mot de passe : mettez-le à jour (étape 7). C'est la cause de 1 compte verrouillé sur 3. |
| « Ce mot de passe a déjà été utilisé » | Choisissez une phrase de passe que vous n'avez jamais utilisée. |
| Je n'ai plus mon téléphone pour le MFA | Le libre-service est impossible : contactez le soutien TI (vérification d'identité requise). |
