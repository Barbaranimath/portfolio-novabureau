# Activer et utiliser le MFA

**Objectif** : ajouter une deuxième vérification à votre compte pour qu'un mot de passe volé ne suffise pas. · **Temps** : 5 min · **Obligatoire** pour tous depuis le 2026-11-15

## Pourquoi ?

Le MFA (authentification multifacteur) combine **ce que vous savez** (mot de passe) et **ce que vous avez** (votre téléphone). Même si un fraudeur obtient votre mot de passe, il ne peut pas se connecter sans votre téléphone.

## Étapes d'activation

1. Sur votre téléphone, installez l'application **Microsoft Authenticator** (App Store ou Google Play).
2. Sur votre ordinateur, connectez-vous à la page **Mes informations de sécurité** de Microsoft 365.
3. Cliquez sur **Ajouter une méthode** → **Application d'authentification**.
4. Dans l'application sur votre téléphone, touchez **+** → **Compte professionnel** → **Scanner un code QR**.
5. Scannez le code QR affiché à l'écran de votre ordinateur.
6. Approuvez la notification de test et entrez le nombre affiché.
7. Ajoutez une **méthode de secours** (numéro de téléphone) au cas où vous perdriez votre appareil.

## Au quotidien

- Une demande apparaît lorsque vous vous connectez depuis un nouvel appareil ou à distance : entrez le nombre affiché à l'écran.
- **Une demande que vous n'avez pas déclenchée ? Refusez-la et appelez le poste 2020** : quelqu'un connaît probablement votre mot de passe.

## Changer de téléphone

1. **Avant** de vous départir de l'ancien appareil, installez Authenticator sur le nouveau.
2. Ajoutez le nouveau téléphone dans **Mes informations de sécurité** (étapes 3 à 6).
3. Supprimez l'ancien téléphone de la liste.

## Erreurs fréquentes

| Problème | Solution |
|---|---|
| Je ne reçois pas les notifications | Activez les notifications de l'application et vérifiez la connexion du téléphone |
| J'ai perdu mon téléphone | Contactez immédiatement le soutien TI : nous retirerons l'appareil perdu après vérification de votre identité |
| Le code est refusé | Vérifiez que l'heure du téléphone est réglée automatiquement |
