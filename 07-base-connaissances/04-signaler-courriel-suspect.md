# Signaler un courriel suspect

**Objectif** : alerter le soutien TI en un clic pour qu'il protège aussi vos collègues. · **Temps** : 30 secondes

## Étapes

1. **Ne cliquez sur aucun lien**, n'ouvrez aucune pièce jointe et ne répondez pas.
2. Dans Outlook, sélectionnez le message.
3. Cliquez sur **Signaler** → **Hameçonnage** dans la barre du haut.
   - Outlook sur le Web : menu **⋯** → **Signaler** → **Hameçonnage**.
   - Pas de bouton ? Transférez le message **en pièce jointe** à `soutien@novabureau.example`.
4. Le message est retiré de votre boîte et transmis au soutien TI.
5. Attendez les consignes; vous recevrez une réponse dans l'heure.

## Si vous avez déjà cliqué

| Ce qui s'est passé | Quoi faire |
|---|---|
| J'ai cliqué, sans rien saisir | Signalez quand même et précisez « j'ai cliqué » |
| J'ai saisi mon mot de passe | Appelez **immédiatement** le poste 2020 |
| J'ai ouvert une pièce jointe | Débranchez le réseau, n'éteignez pas l'ordinateur, appelez le poste 2020 |

**Personne ne sera blâmé.** Plus vous signalez tôt, plus les dégâts sont limités.

## Erreurs fréquentes

- **Supprimer sans signaler** : vos collègues ont peut-être reçu le même message.
- **Transférer à des collègues pour leur demander leur avis** : cela multiplie les risques de clic.
- **Répondre à l'expéditeur pour vérifier** : vous confirmez que votre adresse est active.
