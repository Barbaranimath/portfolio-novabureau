# Installer l'imprimante réseau

**Objectif** : imprimer sur la multifonction du bureau (PRN-01, près de l'Administration). · **Temps** : 3 min · **Prérequis** : être au bureau ou connecté au VPN

## Étapes

1. Ouvrez **Paramètres** → **Bluetooth et appareils** → **Imprimantes et scanners**.
2. Cliquez sur **Ajouter un appareil** et attendez quelques secondes.
3. Sélectionnez **PRN-01-Administration** dans la liste.
   - Elle n'apparaît pas ? Cliquez sur **Ajouter manuellement** → **Ajouter une imprimante à l'aide d'une adresse TCP/IP** → entrez `prn-01.novabureau.local`.
4. Attendez l'installation automatique du pilote.
5. Imprimez une **page de test** pour confirmer.
6. Pour les documents confidentiels (RH, Finance), choisissez **Impression sécurisée** dans les options et libérez l'impression avec votre code à l'imprimante.

## Erreurs fréquentes

| Problème | Solution |
|---|---|
| L'imprimante n'apparaît pas | Vérifiez que vous êtes sur le Wi-Fi **Employés** (pas Invités) ou connecté au VPN |
| « Pilote non disponible » | Installez « Pilote imprimante NovaBureau » depuis le **Portail d'entreprise** |
| Document bloqué dans la file d'attente | Annulez tous les documents de la file, puis redémarrez le service d'impression ou l'ordinateur |
| L'impression sort en noir et blanc | Dans **Propriétés de l'imprimante**, choisissez « Couleur » (les impressions couleur sont comptabilisées par département) |
